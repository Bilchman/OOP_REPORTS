Варіант №3

Мета

  4. Навчитись використовувати метод ToString() для перетворення об’єктів в його рядкове подання.

Умова

Створити консольний застосунок мовою C#. Вхідні дані ввести з клавіатури. Результати вивести на консоль. Використати методи класів Console, Convert в процесі введення та виведення даних. Реалізувати перераховані завдання у вигляді методів класу Program. Виклик методів здійснити за допомогою меню, застосувавши оператор вибору switch.   2. За даними, що введені з консолі, визначити значення виразу, використовуючи математичні функції класу Math, і вивести результат на консоль.
  3. Обчислити значення функції в точці х, значення якої ввести з консолі:
  4. Написати метод, який в залежності від порядкового номера місяця року (1, 2,..., 12) виводить на екран пору року (зима, весна....)
  5. Дано натуральне число n. Обчислити

Аналіз

  1. Для виведення інформації про автора просто зробимо окремий метод з Console.WriteLine().
  2. Для підрахунку поліному спочатку зчитаємо з консолі значення x та порахуємо вираз за допомогою базових операцій * / + - та виведемо результат.
  3. Для підразунку виразу за допомогою Math спочатку зчитаємо a та b причому необхідно додати перевірку, щоб a було більше b. Далі підрахуємо результат за допомогою класу Math: Math.Pow(a + b, 2) / Math.Pow(a - b, 2) + Math.Pow(e, a - 1); та виведемо його.
  4. Для підрахунку функції спочатку треба визначити значення x та за допомогою if-else визначити який вираз необхідно поразувати, після чого вивести рузельтат функції.
  5. Для визначення місяців треба зчитати його номер з консолі, причому обмеживши можливі значення від 1 до 12, а далі за допомогою switch-case визначити пору року та вивести відповідь.
  6. Для підрахунку суми зчитаємо n з консолі, причому n має бути більше або рівне 1, після чого оскількі початкові a і b ряду нам відомі то ми можемо одразу порахувати перший член суми, а саме 3, після чого порахуємо наступні a і b відповідно наданим формулам, помножимо та додамо до суми. Це відбуватимется до тих пір доки i не досягне n.
  • Також створимо допоміжний метод input() для перевірки введенний значень. Даний метод перевірятиме за допомогою TryParse() чи є введені символи числами, та у разі введення літер або інших не чисельних символів проситиме ввести ціле, або дробове число відповідно, за допомогою перевантаження методу.

            Console.WriteLine("Calculate the value of polinom: p = 2x^5 + 3x^4 + 5x + 10");

        /// <summary>
        /// Обчислення значення виразу з використанням методів класу Math
        /// </summary>
        static void calcWithMath()
        {
            Console.WriteLine("Calculate the value of x = (a + b)^2 / (a - b)^2 + e^(a - 1)");

            const double e = 2.72; // константа e
            double a = 1;
            double b = 1;

            while (a == b) // перевірка на те, що a і b не рівні, щоб не було ділення на нуль
            {
                Console.Write("Enter a: ");
                input(out a);
                Console.Write("Enter b: ");
                input(out b);

                    Console.WriteLine("a and b have to be different numbers, try again");
            }

            double x = Math.Pow(a + b, 2) / Math.Pow(a - b, 2) + Math.Pow(e, a - 1);
            Console.WriteLine("x is equal to " + x);
        }

        /// <summary>
        /// Обчислення значення функції, заданої формулою з умовами на x
        /// </summary>
        static void calcFunction()
        {
            Console.WriteLine("       { (sin(x))^2  , x > 0");
            Console.WriteLine("f(x) = { 1 + 2cos(x) , x < 0");
            Console.WriteLine("       {      1      , x = 0");

            Console.Write("Enter x: ");
            input(out double x);
            double f = 1; // за замовчуванням f = 1, якщо x = 0

            // обчислення значення функції в залежності від умови на x
            if (x > 0)
                f = Math.Pow(Math.Sin(x), 2);
            else if (x < 0)
                f = 1 + 2 * Math.Cos(x);

            Console.WriteLine("f(x) is equal to " + f);
        }

        /// <summary>
        /// Переведення номера місяця в пору року
        /// </summary>
        static void monthToSeason()
        {
            int m = 0;

            while (m < 1 || m > 12) // перевірка на те, що введене число є номером місяця
            {
                Console.Write("Enter month number: ");
                input(out m);
                if (m < 1 || m > 12) // якщо число не є номером місяця, виводимо повідомлення і просимо ввести ще раз
                    Console.WriteLine("It`s not a month number, try again");
            }

                case < 3: Console.WriteLine("It`s Winter"); break;
                case < 6: Console.WriteLine("It`s Spring"); break;
                case < 9: Console.WriteLine("It`s Summer"); break;
                case < 12: Console.WriteLine("It`s Autumn"); break;
                case 12: Console.WriteLine("It`s Winter"); break;
            }
        }

        /// <summary>
        /// Обчислення суми заданого ряду з рекурентними співвідношеннями для a(k) та b(k)
        /// </summary>
        static void calcSum()
        {
            Console.WriteLine("     n                 ");
            Console.WriteLine("    ___                a(1) = 1;  a(k) = 3b(k - 1) + 1,");
            Console.WriteLine("    \\                                                             for k > 1");
            Console.WriteLine("S = /__ a(i) * b(i),   b(1) = 3;  b(k) = 1/2 * a(k) - b(k - 1),");

            Console.Write("Enter integer n: ");
            int n = 0;
            while (n < 1)
            {
                input(out n);
                if (n < 0)
                    Console.WriteLine("n has to be equal or more than 1.");

                sum += a * b;
            }

            Console.WriteLine("Sum is " + sum);

        /// Перевірка введення дробово-чисельної змінної

Аналіз

  1. Для генерації масиву використовуватимемо клас Random. Перед генерацією зчитаємо кількість та діапазон значень. Залежно від введеного діапазону зробимо різні режими генерації для правильного утворення додатніх та від'ємних значень. Сортування зробимо за класичним алгоритмом сортування вставкою. Виведення масиву буде виконан через використання типізованого методу виведення масиву printArray().
  2. Для визначення простих чисел створимо булевий масив що міститиме дані про те які числа є простими від 0 до максимального значення елемента у масиві. За допомогою решета Ератосфена визначемо прості числа та запишемо результат до булевого масиву. Далі пройдемося по масиву елементів та виводитиме лише ті, що записані як прості у булевому масиві.
  3. Щоб переставити елементи у порядку від'ємні, додатні, нулі варто спочатку перестаити додатні елементи у кінець масиву, а потім нульові. Проте щоб зберегти порядок між елементами одного знаку варто проходити з кінця масиву та переставляти перший знайдений додатній елемент у кінець, потім наступний на передостанню позицію, а так далі, поки всі додатні елементи не будуть перемішені у кінець, після чого прото переставляємо нульові елементи у кінець масиву.
  4. Щоб визначити найменший додатній елемент, варто визначити перший додатній елемент у масіві і, якщо такий існує, порівнювати його з рештою додатніх елементів у масиві поки не буде знайдено найменший серед них. Для знаходження найбільшого від'ємного значення робитимемо аналогічно.
  5. Для знаходження всіх кратних вимагають використовувати бінарний пошук замість традиційної перевірки остачі. Отже, перш за все визначимо найбільше за модулем число у масиві та, за допомогою бінарного пошуку, шукатимемо додатне та від'ємне значення заданого числа а потім збільшувати за модулем на саме ж шукане число до тих пір, поки воно менше або дорівнює максимальному за модулем елементу. Таким чином ми переглянемо всі можливі складні числа, що мають у складі шукане число та зможемо визначити чи присутні вони у масиві.
  6. Матрицю згенеруємо зчитавши її розміри та діапазон прибутку і використавши клас Random. Виводитимемо матрицю у вигляді таблиці з місяцями та товарами, де на перетині показаний прибуток відповідного товару за певний місяць. Крім того додамо додаткові колонку та стовпець що показуватимуть загальний прибуток за кожен місяць та з кожного товару і загальний прибуток.
  7. Пошук максимального значення у матриці здійснюватимемо через лінійній пошук найбільшого елементу та запам'ятання його позиції і подальше виведення результат. Пошук найменшого значення здійснюватимемо аналогічно.
  8. Для знаходження коренів спочатку знайдемо проміжок на якому знаки функції будуть різними, після чого за допомогою методу половинного ділення шукатимемо наближений корінь рівняння.
  9. Для перевірки правильності розставлення дужок створимо список, в якому зберігатимуться дані про відкриті та закриті дужки.     /// <summary>
    /// Функція для обчислення значення нелінійного рівняння (x^2 − 5x + 7)^2 − (x − 2)(x − 3) = 0.
    /// </summary>
    /// <param name="x">Значення x</param>
    /// <returns>Результат обчислення</returns>
    static double F(double x)
    {
        return Math.Pow(x * x - 5 * x + 7, 2) - (x - 2) * (x - 3);
    }
    /// <summary>
    /// Пошук коренів нелінійного рівняння за допомогою методу половинного ділення на заданому інтервалі [a, b] з точністю eps.
    /// </summary>
    /// <param name="a">Ліва межа інтервалу</param>
    /// <param name="b">Права межа інтервалу</param>
    /// <param name="eps">Точність</param>
    /// <returns>Корінь рівняння або NaN, якщо корінь не знайдено</returns>
    static double bisection(double a, double b, double eps = 1e-12)
    {
        if (F(a) * F(b) > 0)
            return double.NaN; // Немає коренів на цьому інтервалі

        double c = a;
        while ((b - a) / 2 > eps)
        {
            c = (a + b) / 2;
            double fc = F(c);

            if (Math.Abs(fc) < eps)
                return c;

            if (F(a) * fc < 0)
                b = c;
            else
                a = c;
        }

        return (a + b) / 2; // Повертаємо середину інтервалу як наближення кореня
    }
    /// <summary>
    /// Пошук усіх коренів нелінійного рівняння на заданому інтервалі з кроком step та точністю eps.
    /// </summary>
    /// <param name="start">Ліва межа інтервалу</param>
    /// <param name="end">Права межа інтервалу</param>
    /// <param name="step">Крок</param>
    /// <param name="eps">Точність</param>
    static void findAllRoots(double start = -10, double end = 10, double step = 0.1, double eps = 1e-12)
    {
        List<double> roots = new List<double>();

        double a = start;
        double b = a + step;

        while (b <= end)
        {
            if (F(a) * F(b) < 0)
            {
                double root = bisection(a, b, eps);

                bool exists = false;

                for(int i = 0; i < roots.Count() && exists == false; i++)
                {
                    if (Math.Abs(roots[i] - root) < 1e-10)
                        exists = true;
                }

                if (double.IsNaN(root) == false && exists == false)
                {
                    roots.Add(root);
                }
            }

            a = b;
            b = a + step;
        }

        if (roots.Count == 0)
        {
            Console.WriteLine("No roots found on the interval.");
            return;
        }

        Console.WriteLine("Found roots:");
        foreach (var r in roots)
            Console.WriteLine($"x = {r:F5}, F(x) = {F(r):F5}| {checkAnswer(r)}");
    }

        {
            switch (text[i])
            {
                case '(':
                {
                    brackets.Add(1);
                    break;
                }
                case '[':
                {
                    brackets.Add(2);
                    break;
                }
                case '{':
                {
                    brackets.Add(3);
                    break;
                }
                case ')':
                {
                    if (brackets[brackets.Count - 1] == 1)
                        brackets.RemoveAt(brackets.Count - 1);
                    else
                        wrongBracketSequance = true;
                    break;
                }
                case ']':
                {

                        brackets.RemoveAt(brackets.Count - 1);
                    else
                        wrongBracketSequance = true;
                    break;

                    if (brackets[brackets.Count - 1] == 3)
                        brackets.RemoveAt(brackets.Count - 1);
                    else
                        wrongBracketSequance = true;
                    break;
                }
            }
        }
        if (brackets.Count == 0 && wrongBracketSequance == false)
            Console.WriteLine("The sequence is correct");
        else
            Console.WriteLine("The sequence is incorrect");

            File.WriteAllText(Path, "=== PROGRAM RESULTS ===\n\n");

        /// </summary>
        /// <param name="text">Текст для запису.</param>
        public static void WriteLine(string text)
        {
            Console.WriteLine(text);
            File.AppendAllText(Path, text + "\n");
        }

        /// <summary>
        /// Записує текст у консоль та додає його у файл лога без переходу на новий рядок.
        /// </summary>
        /// <param name="text">Текст для запису.</param>
        public static void Write(string text)
        {
            Console.Write(text);
            File.AppendAllText(Path, text);
        }

        /// <summary>
        /// Виведення масиву на екран.
        /// </summary>
        /// <typeparam name="T">Тип елементів масиву</typeparam>
        /// <param name="array">Масив для виведення</param>
        public static void LogArray<T>(T[] array)
        {
            StringBuilder sb = new StringBuilder();
            foreach (T i in array)
                sb.Append(i + " ");
            Log.WriteLine(sb.ToString());
        }
    }

        /// </summary>
        /// <param name="array">Масив цілих чисел для пошуку простих чисел.</param>
        public static void LookForPrime(int[] array)
        {
            int maxNum = array.Max();
            bool prime = false;
            bool[] isPrime = new bool[maxNum + 1];

            for (int i = 0; i < isPrime.Length; i++) // Ініціалізуємо всі числа як прості
                isPrime[i] = true;

            // 0 і 1 не є простими числами
            if (isPrime.Length > 0) isPrime[0] = false;
            if (isPrime.Length > 1) isPrime[1] = false;

            // Використовуємо решето Ератосфена для позначення складних чисел
            for (int i = 2; i * i < isPrime.Length; i++)
                if (isPrime[i])
                    for (int j = 2 * i; j < isPrime.Length; j += i)
                        isPrime[j] = false;

            // Перевіряємо, чи є серед додатніх елементів масиву прості числа
            for (int i = 0; i < isPrime.Length; i++)
                if (isPrime[i] == true)
                    prime = true;

            if (prime == true)
            {
                StringBuilder sb = new StringBuilder();
                sb.Append("Prime numbers:");
                for (int i = 0; i < array.Length; i++)
                {
                    if (array[i] > 1)
                        if (isPrime[array[i]] == true)
                            sb.Append(" " + array[i]);
                }
                Log.WriteLine(sb.ToString());
            }
            else
                Log.WriteLine("There is no prime numbers in the array");
        }
        /// <summary>
        /// Перестановка додатніх і від’ємних елементів масиву.
        /// </summary>
        /// <param name="array">Масив цілих чисел для перестановки.</param>
        public static void Shuffle(int[] array)
        {
            int n = array.Length - 1;
            for (int i = array.Length - 1; i >= 0; i--)
            {
                if (array[i] > 0)
                {
                    int temp = array[i];
                    for (int j = i; j < n; j++)
                    {
                        array[j] = array[j + 1];
                    }
                    array[n--] = temp;
                }
            }
            for (int i = array.Length - 1; i >= 0; i--)
            {
                if (array[i] == 0)
                {
                    int temp = array[i];
                    for (int j = i; j < array.Length - 1; j++)
                    {
                        array[j] = array[j + 1];
                    }
                    array[array.Length - 1] = temp;
                }
            }
        }

                    case '[':
                        {
                            brackets.Add(2);
                            break;
                        }
                    case '{':
                        {
                            brackets.Add(3);
                            break;
                        }
                    case ')':
                        {
                            if (brackets.Count > 0 && brackets[brackets.Count - 1] == 1)
                                brackets.RemoveAt(brackets.Count - 1);
                            else
                                wrongBracketSequance = true;

                        }

                            break;
                        }

Висновки

У ході виконання лабораторної роботи було розроблено консольний застосунок мовою C# для обробки даних про факультет і кафедру з використанням можливостей об’єктно-орієнтованого програмування. Створено класи Faculty та Department із закритими полями, конструкторами без параметрів і з параметрами, а також відкритими властивостями (get, set) для забезпечення інкапсуляції та контролю коректності введених даних. Було реалізовано методи введення та виведення інформації через консоль із перевіркою правильності даних за допомогою TryParse() та внутрішньої валідації у властивостях. Для збереження результатів роботи програми використано текстовий файл із застосуванням класів StreamWriter і File, а також створено окремий статичний клас Log для одночасного виведення інформації в консоль і запису її до файлу. У класі Faculty реалізовано метод корегування кількості спеціальностей і кафедр відповідно до кількості студентів із врахуванням умови мінімальної кількості 200 студентів на спеціальність та принципу відповідності «одна спеціальність — одна кафедра». У класі Department реалізовано метод розрахунку навчального навантаження одного викладача з урахуванням співвідношення студентів і викладачів 10:1, мінімального обсягу дисципліни 90 годин і максимально допустимого річного навантаження 600 годин. Клас Department подано як partial та розділено на декілька файлів, у яких окремо реалізовано метод розрахунку навантаження викладачів і метод покращення якості підготовки студентів. Додатково створено вкладений клас BranchDepartment, що моделює філію кафедри в ІТ-компанії, із реалізацією розрахунку індексу KPI за заданою формулою та оптимізації витрат із використанням генерації випадкових значень класом Random. Також до проєкту додано статичний клас CompanyProject, у якому реалізовано алгоритм пошуку простих чисел (решето Ератосфена), алгоритм перестановки елементів масиву та перевірку правильності послідовності дужок у рядку. У результаті виконання роботи було закріплено навички створення та модифікації класів, використання конструкторів і властивостей, застосування вкладених і часткових класів, реалізації статичних методів, роботи з текстовими файлами та побудови структурованого консольного застосунку з логуванням результатів.
